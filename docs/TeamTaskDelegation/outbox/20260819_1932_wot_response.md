# Response: IntroScene용 2D UI 위젯 렌더링 계약

## Delivered Interface

- `ui/widgets/IUiBase.h` — `virtual void Render() = 0;`만 갖는 최소 위젯 계약.
- `ui/widgets/IUiElementRegistry.h` — `Add(IUiBase*)` / `Remove(IUiBase*)` / `RenderAll()`. non-owning(수명 관리는 호출자 책임).
- `ui/widgets/UiElementRegistry.h/.cpp` — `IUiElementRegistry`의 기본 구현체(`std::vector<IUiBase*>` 기반). WOT이 별도로 구현할 필요 없이 바로 사용 가능.
- `ui/widgets/ButtonUI.h` — `ButtonUI(std::string label, std::function<void()> onClick = nullptr)`. `ImGui::Button` wrapper, 클릭 시 `onClick` 호출.
- `ui/widgets/ProgressUI.h` — `ProgressUI(const float* fraction, std::string overlayLabel = "")`. `fraction`은 non-owning 포인터 — 매 프레임 최신값을 읽으므로 호출자가 그 값을 직접 갱신해야 한다.
- `ui/widgets/StringFieldUI.h` — `StringFieldUI(std::string label, std::string* buffer, std::size_t bufferCapacity = 256)`. `ImGui::InputText` wrapper, `*buffer`를 직접 편집.
- `ui/widgets/LabelUI.h` — `LabelUI(std::string text)` + `SetText(std::string)`. `ImGui::TextUnformatted` wrapper(이유는 Deviations 참고).
- `ui/widgets/ImageUI.h` — `ImageUI(void* textureHandle, float width, float height, std::function<void()> onClick = nullptr)`. `onClick`이 있으면 `ImGui::ImageButton`, 없으면 `ImGui::Image`.
- `renderer/IRenderer.h`에 `virtual void SetUiElementRegistry(IUiElementRegistry& registry) = 0;` 추가 — `DirectX9Renderer`/`DirectX11Renderer`/`DirectX12Renderer`가 `RenderFrame()` 내부에서 `NewFrame()` 직후 등록된 registry의 `RenderAll()`을 호출하도록 배선했다. `OpenGLRenderer`는 no-op.

사용 예시(WOT `IntroScene` 쪽 통합 시):

```cpp
UiElementRegistry registry;
ButtonUI startButton("Start", []() { /* ... */ });
registry.Add(&startButton);

renderer->SetUiElementRegistry(registry);  // Scene 진입 시 1회
// registry, startButton은 Scene이 살아있는 동안 유효해야 한다(non-owning).
```

## Compatibility

**backward-compatible** — 기존 `IRenderer` 사용 코드(`RendererFactory`가 반환하는 `IRenderer*`를 통한 `Initialize`/`RenderFrame`/`OnResize`/`Shutdown`/`HandleUiMessage` 호출)는 변경 없이 그대로 동작한다.

다만 `IRenderer`에 새 순수가상함수(`SetUiElementRegistry`)가 추가됐다 — `IRenderer`를 그래픽스 저장소 밖에서 직접 상속/구현하는 코드가 있다면 컴파일이 깨진다. 현재 이 인터페이스의 구현체는 graphics 저장소 내부(`DirectX9Renderer`/`DirectX11Renderer`/`DirectX12Renderer`/`OpenGLRenderer`)뿐이며, WOT은 `IRenderer`를 구현하지 않고 `RendererFactory`가 만든 인스턴스를 사용만 하므로 영향 없다.

## Deviations from Request

- **`ImageUI` 텍스처 파라미터를 `ImTextureID`가 아닌 `void*`로 변경**: `ImGui::Image`/`ImGui::ImageButton`이 받는 `ImTextureRef`가 `void*`를 받는 암시적 생성자를 제공한다 — `void*`를 쓰면 `ImageUI.h`가 `imgui.h`를 include하지 않고도 텍스처를 표현할 수 있어, "graphics 내부에서도 위젯 헤더는 imgui.h를 노출하지 않는다"는 경계를 한 단계 더 지킬 수 있다. 사용법은 동일 — 백엔드에서 얻은 텍스처 포인터를 그대로 넘기면 된다.
- **`LabelUI`는 `ImGui::Text`가 아니라 `ImGui::TextUnformatted`를 사용**: `text`를 그대로 포맷 문자열로 넘기면 `%` 문자가 포함된 텍스트에서 정의되지 않은 동작이 생긴다 — 보안/안정성 상 `TextUnformatted`가 맞는 선택이라 판단해 변경했다. 동작(문자열을 그대로 표시)은 요청과 동일하다.
- **위젯 생성자 파라미터는 요청에 없던 부분이라 graphics가 정함** (Brainstorming Q4) — 위 Delivered Interface의 시그니처가 최종본이다. 부족한 부분이 있으면 새 요청으로 알려달라.
- **`ImageUI`의 Image/ImageButton 분기 기준은 "클릭 콜백(`onClick`) 유무"로 확정** (Brainstorming Q3, WOT 쪽에 직접 확인 완료).

## Version

`v0.1.0` (graphics 저장소 최초 태그 릴리스 — 이전 태그 없음).

## 참고: WOT 쪽 후속 조치 필요

`World-of-Tank-imitation-Refactoring/CMakeLists.txt`의 `graphics_lib` 소스 목록이 graphics 쪽 `CMakeLists.txt`와 수동 동기화되는 구조다 (`graphics/CMakeLists.txt` 주석 참고). 이번에 추가된 `ui/widgets/*.cpp` 6개 파일을 WOT의 `graphics_lib` 목록에도 추가해야 링크된다 — 서브모듈 pin을 이 버전으로 올릴 때 함께 반영 필요.
