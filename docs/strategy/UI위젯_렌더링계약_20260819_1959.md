# Strategy: WOT 요청 — IntroScene용 2D UI 위젯 렌더링 계약

Cross-repo 의존성 검토: 아래 모든 항목이 `graphics` 저장소 내부에서 완결된다. `platform`의 신규/변경 기능이 필요한 항목은 없으므로 전부 `[self]`이며, `team_task_delegation.md`를 추가로 거칠 항목이 없다.

## Checklist

- [x] `[self]` `ui/widgets/IUiBase.h` 작성 — `virtual void Render() = 0;`, `virtual ~IUiBase() = default;`
- [x] `[self]` `ui/widgets/IUiElementRegistry.h` 작성 — `Add(IUiBase*)` / `Remove(IUiBase*)` / `RenderAll()`
- [x] `[self]` `ui/widgets/UiElementRegistry.h/.cpp` 작성 — `IUiElementRegistry`의 기본 구현체, `std::vector<IUiBase*>` 기반 non-owning 컨테이너 (projects 종속 없음, Brainstorming Q1)
- [x] `[self]` `ui/widgets/ButtonUI.h/.cpp` — `ImGui::Button` wrapper
- [x] `[self]` `ui/widgets/ProgressUI.h/.cpp` — `ImGui::ProgressBar` wrapper
- [x] `[self]` `ui/widgets/StringFieldUI.h/.cpp` — `ImGui::InputText` wrapper
- [x] `[self]` `ui/widgets/LabelUI.h/.cpp` — `ImGui::Text` wrapper
- [x] `[self]` `ui/widgets/ImageUI.h/.cpp` — `onClick` 콜백 유무로 `ImGui::ImageButton`/`ImGui::Image` 분기 (Brainstorming Q3). 구현 중 텍스처 파라미터를 `ImTextureID`가 아닌 `void*`로 조정 — Deviations 참고.
- [x] `[self]` `renderer/IRenderer.h`에 `virtual void SetUiElementRegistry(IUiElementRegistry& registry) = 0;` 추가 (요청 원문의 레퍼런스 시그니처 유지, Brainstorming Q2)
- [x] `[self]` `DirectX9Renderer`/`DirectX11Renderer`/`DirectX12Renderer`: `IUiElementRegistry*` 멤버(초기값 `nullptr`) 추가, `SetUiElementRegistry` 구현(주소 저장), `RenderFrame` 내부 `m_uiManager->NewFrame()` 이후 · `m_uiManager->Render()` 이전에 `if (m_uiElementRegistry) { m_uiElementRegistry->RenderAll(); }` 배선
- [x] `[self]` `OpenGLRenderer`: `SetUiElementRegistry` no-op 구현 (컴파일 통과 목적, 실제 배선 없음)
- [x] `[self]` 단위 테스트: `UiElementRegistryTest`(Add/Remove/RenderAll을 mock `IUiBase`로 검증), `UiWidgetsTest`(5종 위젯 wrapper의 생성/`Render()` 호출 스모크 테스트), DX9/11/12 `RendererTest`에 `SetUiElementRegistry`가 `RenderFrame`에서 실제로 `RenderAll()`을 호출하는지 검증하는 테스트 추가
- [x] `[self]` `CMakeLists.txt`에 신규 소스(`ui/widgets/*.cpp`)와 테스트 파일 등록
- [x] `[self]` 빌드 + 전체 테스트 통과 확인 — 37/37 테스트 통과 (신규 9개 포함)
- [x] `[self]` `docs/outbox/20260819_1932_wot_response.md` 작성 (Delivered interface / Compatibility / Deviations / Version)
- [ ] `[self]` `team_task_delegation.md` Step 3 후속 절차(커밋, main으로 merge, 버전 태그, request 브랜치 삭제) — 사용자 승인 후 진행

## Verification Criteria

- 신규 파일들은 `agent_harness/CLAUDE.md`의 Comment Writing Rules(작성자/설명/입력/출력/비고/작성일)를 모두 포함한다.
- `ui/widgets/*.cpp` 외 다른 모듈(`renderer/`, `main.cpp` 등)에서 `imgui.h`를 직접 포함하지 않는다 — wrapper 경계 유지 확인.
- `IUiElementRegistry`/`UiElementRegistry`는 `IUiBase`의 구체 서브클래스를 알지 못한다(순수 포인터만 다룸) — SRP 검증.
- 빌드(`CMakeLists.txt` 기반) 및 전체 단위 테스트가 그린 상태여야 Step 4 완료로 간주.
