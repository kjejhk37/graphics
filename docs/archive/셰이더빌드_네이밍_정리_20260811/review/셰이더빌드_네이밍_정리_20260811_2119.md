# Code Review: 셰이더 빌드 파이프라인 네이밍 정리

## Stage 1 — Quality Inspection

이번 사이클은 기존 코드의 심볼명만 `wot_`/`WOT_` → `graphics_`/`GRAPHICS_`로 바꾼 순수 리네이밍이다.
새 클래스/함수/로직이 추가되지 않았고, 외부 라이브러리 사용 경로도 변경되지 않았다.

- **SOLID 원칙**: 해당 없음 — 함수/로직 구조 변경 없음, 이름만 변경.
- **라이브러리 격리**: 위반 없음 — 변경 범위 밖.
- **단위 테스트**: 충족 — 리네이밍 후 `ctest` 28개 전부 재실행해 Passed 확인, 회귀 없음.
- **주석 규칙**: 위반 없음 — `graphics_add_hlsl_shader()`의 Author/Description/Input/Output/Notes/Date 헤더 주석은 이전 사이클에서 이미 추가된 상태로 유지됨(함수명 줄만 교체).

**발견된 이슈 없음.**
