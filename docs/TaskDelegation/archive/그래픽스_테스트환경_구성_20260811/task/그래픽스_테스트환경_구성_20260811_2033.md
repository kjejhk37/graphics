# Task: 그래픽스 단위 테스트 환경 구성

## Purpose

graphics 저장소 안에, platform이 같은 부모 폴더의 형제 디렉터리로 존재한다는 전제 하에 독립적인 단위 테스트 빌드/실행 환경(CMake + GoogleTest)을 구성한다.
World-of-Tank-imitation-Refactoring(projects)의 CMake 빌드에 얹혀가지 않고도 graphics 저장소 혼자서 테스트를 빌드/실행할 수 있게 한다.

## Author

(비워둠)

## User draft

- graphics / platform / projects(World-of-Tank-imitation-Refactoring) 세 저장소가 있고, projects는 graphics·platform 둘 다 git submodule로 사용한다.
- graphics는 platform에 의존하지만, graphics 저장소 안에 platform을 submodule로 넣는 것은 애매한 상태다.
- 그래도 graphics는 최소한 단위 테스트는 가지고 있어야 한다.
- 해결 방향: graphics가 platform을 submodule로 갖지 않고, "같은 폴더에 나란히 있다"는 전제(현재 실제 배치: `Claude/graphics`, `Claude/platform`)로 상대 경로를 통해 platform을 참조하는 자체 CMake 테스트 빌드를 graphics 안에 구성한다.

## Requirements

기존 projects(World-of-Tank-imitation-Refactoring) 저장소의 `docs/architecture/platform_graphics_projects.md`와 `docs/archive/src구조재편_20260806/strategy/`를 조사해 아래 내용을 확인했다.

1. **테스트 프레임워크**: GoogleTest(FetchContent, projects와 동일하게 v1.17.0) — 두 저장소의 테스트 형식/도구를 통일한다.
2. **platform 참조 방식**: 하드코딩된 `../platform`이 아니라 CMake 캐시 변수(예: `GRAPHICS_PLATFORM_DIR`, 기본값 `${CMAKE_SOURCE_DIR}/../platform`)로 — 실제 배치와 일치시키되 위치가 바뀌어도 대응 가능하게 한다.
3. **테스트 이전 범위**: projects의 `docs/archive/src구조재편_20260806/strategy/src구조재편_20260806_2232.md`에 이미 "Phase B(별도 저장소 추출)에서 platform 테스트를 platform 자체 저장소로 옮겨야 한다"는 방향이 기록되어 있고, graphics/platform 두 저장소는 이미 Phase B가 실행된 상태(분리된 git 저장소로 존재)다. 따라서 projects/tests에 있는 graphics_lib 관련 테스트를 graphics/tests로 이전하는 것이 기존에 이미 정해진 방향과 일치한다.
   - 대상 후보: `RendererFactoryTest`, `RendererBackendParserTest`, `ShaderBytecodeLoaderTest`, `DirectX9/11/12RendererTest`, `ImGuiManagerDX9/11/12Test`, `DirectX11/12ComputeDemoTest`.
   - 위 파일들의 `#include`를 확인한 결과 `platform/...` 헤더만 참조하고 `projects/...`는 참조하지 않아, projects 고유 타입 없이 이전이 가능해 보인다(실제 이전 여부와 세부 방법은 Step 2/3에서 확정).
4. **graphics 최상위 CLAUDE.md**: 현재 없음(`World-of-Tank-imitation-Refactoring`과 달리 `@agent_harness/CLAUDE.md`를 import하는 파일이 없어, 이번에 `docs/`를 만들어 Task Delegation 워크플로우를 쓰는 것 자체가 문서화되어 있지 않다). 이번 작업 범위에 포함해 최소한의 root `CLAUDE.md`(agent_harness import)를 추가한다.
