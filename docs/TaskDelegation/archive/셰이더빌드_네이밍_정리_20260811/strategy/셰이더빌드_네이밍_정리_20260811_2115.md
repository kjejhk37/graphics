# Strategy: 셰이더 빌드 파이프라인 네이밍 정리

## 확정된 방향 (브레인스토밍 결과 요약)

- `wot_`/`WOT_` 접두어를 전부 `graphics_`/`GRAPHICS_`로 통일한다 (함수/로컬 변수/리스트 변수/컴파일 정의).
- `WOT_SHADER_OUTPUT_DIR`도 `GRAPHICS_SHADER_OUTPUT_DIR`로 바꾸고, 이를 참조하는 `tests/ShaderBytecodeLoaderTest.cpp`도 함께 수정한다 (projects 원본과의 1:1 동일성에서 이 한 줄만 예외).

## How — 이름 매핑

| 기존 | 변경 후 |
|---|---|
| `wot_add_hlsl_shader()` | `graphics_add_hlsl_shader()` |
| `_wot_fxc_candidates` | `_graphics_fxc_candidates` |
| `_wot_fxc_search_dirs` | `_graphics_fxc_search_dirs` |
| `_wot_fxc_candidate` (foreach 루프 변수) | `_graphics_fxc_candidate` |
| `_wot_fxc_dir` | `_graphics_fxc_dir` |
| `_wot_dx9_baseline_vs` 등 11개 셰이더별 임시 변수 | `_graphics_dx9_baseline_vs` 등 (동일 패턴 11개) |
| `WOT_SHADER_OUTPUTS` | `GRAPHICS_SHADER_OUTPUTS` |
| `WOT_SHADER_OUTPUT_DIR` (컴파일 정의) | `GRAPHICS_SHADER_OUTPUT_DIR` |

`tests/ShaderBytecodeLoaderTest.cpp`의 `std::string(WOT_SHADER_OUTPUT_DIR)` 참조도 `GRAPHICS_SHADER_OUTPUT_DIR`로 함께 수정한다.

## Checklist

- [x] `graphics/CMakeLists.txt`에서 함수명 `wot_add_hlsl_shader()` → `graphics_add_hlsl_shader()` 변경 (정의부 + 11개 호출부 전부)
- [x] fxc 검색 관련 임시 변수 4종(`_wot_fxc_candidates`, `_wot_fxc_search_dirs`, `_wot_fxc_candidate`, `_wot_fxc_dir`) → `_graphics_fxc_*`로 변경
- [x] 셰이더별 임시 변수 11종(`_wot_dx9_baseline_vs` 등) → `_graphics_*`로 변경 (선언부 + `list(APPEND ...)` 참조부)
- [x] 리스트 변수 `WOT_SHADER_OUTPUTS` → `GRAPHICS_SHADER_OUTPUTS`로 변경 (선언 + `list(APPEND ...)` + `add_custom_target(shaders DEPENDS ...)`)
