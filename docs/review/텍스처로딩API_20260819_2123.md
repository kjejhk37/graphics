# Code Review: WOT 요청 — ImageUI용 텍스처 로딩 공개 API

## Stage 1 — Quality Inspection

발견 사항 없음.

- SOLID: `WicImageLoader`는 "파일 → RGBA8 픽셀"만 책임진다(SRP). `IRenderer`에 `LoadTexture`/`UnloadTexture`를 추가한 것은 이전 사이클의 `SetUiElementRegistry` 전례와 동일한 패턴이라 새로운 위반이 아니다.
- Library Isolation: `<wincodec.h>`는 `renderer/WicImageLoader.cpp` 한 파일에서만 include된다. `DirectX11Renderer.cpp`는 `WicImageLoader`를 통해서만 이미지를 다룬다.
- Unit Tests: `WicImageLoaderTest`(성공 시 치수+픽셀값까지 검증, 실패 케이스), `DirectX11RendererTest`(성공/실패/`ImageUI` 통한 실제 렌더/알 수 없는 핸들 unload 안전성), DX9/DX12 스텁도 항상 `nullptr`/no-op임을 검증하는 최소 테스트 포함 — 전체 45/45 통과.
- Comment Rules: `WicImageLoader` 클래스+`Load()`, `IRenderer.h`/`DirectX11Renderer.h` Notes 갱신, DX9/DX12 스텁 메서드에 개별 주석 모두 Author/Description/Input/Output/Notes/Date 포함.
